# BeyondTrailTales (BTT) - Authentication & Sharing System

## Overview
BeyondTrailTales is a backpacking trip planning application with user authentication, trip sharing, and real-time collaboration features. The system allows users to create accounts, manage their trips and backpacks, share trips with other users, and collaborate in real-time.

**Base URL:** http://localhost/BTT (served by XAMPP on port 80)

## Migrations

### Running Migrations
```bash
# Check migration status
php app/migrations/runner.php status

# Run all pending migrations
php app/migrations/runner.php run

# Rollback last migration (if implemented)
php app/migrations/runner.php rollback
```

### Adding New Migrations
1. Create a new SQL file in `app/migrations/` with naming pattern: `NNNN_description.sql`
2. Include proper PRAGMA statements for foreign keys
3. Use IF NOT EXISTS clauses for idempotency
4. Test migration thoroughly before committing

## Security Configuration

### Password Policy
- Algorithm: BCrypt with cost factor 12
- Minimum length: 12 characters (recommended)
- Complexity: Mixed case, numbers, symbols encouraged
- Storage: Only hashed passwords stored

### CSRF Protection
- Token lifetime: 1 hour
- Token rotation: After sensitive operations
- Validation: All POST/PUT/PATCH/DELETE requests
- Token delivery: Header (X-CSRF-Token) or form field (csrf_token)

### Session Security
- Cookie name: BTTSESSID
- Flags: HttpOnly, SameSite=Lax
- Secure flag: Enabled on HTTPS
- Session regeneration: On login/logout
- Storage: SQLite database with garbage collection

### Rate Limiting
- Login attempts: 5 per email/IP in 15 minutes
- Lockout duration: 15 minutes (exponential backoff)
- Registration: Optional rate limiting
- API calls: 1000 per hour per session

### Token Security
- Email verification: 24-hour expiry
- Password reset: 1-hour expiry
- Remember me: 30-day expiry
- All tokens: Single use, hashed storage

## API Endpoints

### Authentication

#### POST /api/auth/register
Register a new user account.

**Request:**
```json
{
    "email": "user@example.com",
    "username": "johndoe",
    "password": "SecurePassword123!",
    "csrf_token": "..."
}
```

**Response:**
```json
{
    "success": true,
    "message": "Registration successful. Please check your email.",
    "data": {
        "user_id": 1
    }
}
```

#### POST /api/auth/login
Authenticate user and create session.

**Request:**
```json
{
    "login": "user@example.com",
    "password": "SecurePassword123!",
    "remember": true,
    "csrf_token": "..."
}
```

**Response:**
```json
{
    "success": true,
    "message": "Login successful",
    "data": {
        "user": {
            "id": 1,
            "username": "johndoe",
            "email": "user@example.com"
        },
        "csrf_token": "new_token_here"
    }
}
```

#### POST /api/auth/logout
End user session.

**Request:**
```json
{
    "csrf_token": "..."
}
```

#### GET /api/auth/verify-email?token=...
Verify email address with token from email.

#### POST /api/auth/request-password-reset
Request password reset email.

#### POST /api/auth/reset-password
Reset password with token.

#### GET /api/auth/me
Get current user information.

### Sharing

#### POST /api/share/generate-code
Generate share code for trip.

**Request:**
```json
{
    "trip_id": 123,
    "max_uses": 5,
    "expires_in_hours": 24,
    "csrf_token": "..."
}
```

#### POST /api/share/redeem-code
Redeem a share code.

**Request:**
```json
{
    "code": "ABC123",
    "csrf_token": "..."
}
```

### Real-time Collaboration

#### GET /api/collab/stream?trip_id=123&since=0
Server-Sent Events stream for trip updates.

#### POST /api/collab/patch
Submit trip edit patch.

**Request:**
```json
{
    "trip_id": 123,
    "op_type": "field_update",
    "payload": {
        "field": "title",
        "value": "Updated Title"
    },
    "csrf_token": "..."
}
```

## Frontend Integration

### CSRF Token Usage

Include in page head:
```php
<?php
use App\Services\Csrf;
echo Csrf::getMetaTag();
echo Csrf::getAjaxScript();
?>
```

In forms:
```php
<?php echo Csrf::getHiddenField(); ?>
```

In JavaScript:
```javascript
// Token available as window.csrfToken
fetch('/api/endpoint', {
    method: 'POST',
    headers: {
        'X-CSRF-Token': window.csrfToken,
        'Content-Type': 'application/json'
    },
    body: JSON.stringify(data)
});
```

### Authentication Check
```php
<?php
use App\Services\AuthService;

if (!AuthService::isAuthenticated()) {
    header('Location: /BTT/public/auth/login.php?returnTo=' . urlencode($_SERVER['REQUEST_URI']));
    exit;
}

$user = AuthService::getCurrentUser();
?>
```

## Troubleshooting

### Common Issues

#### Migration Errors
- Ensure SQLite has write permissions
- Check for view dependencies
- Verify foreign key constraints

#### Session Issues
- Check session.save_path is writable
- Verify cookie settings match domain
- Clear browser cookies if needed

#### CSRF Token Errors
- Ensure session is started
- Check token expiry (1 hour)
- Verify header name matches

#### Email Not Sending
- Check SMTP configuration
- Verify firewall allows SMTP port
- Check mail.log for errors
