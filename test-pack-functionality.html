2. Drag & Drop Functionality

Manual Test Steps

  1. Test Drag & Drop:
    • Drag a gear item from the library to a pack section
    • Verify the item appears with correct data
    • Try dragging items between sections
  2. Test Section Toggle:
    • Click the arrow button (▼/▶) on a section header
    • Verify the section expands/collapses
    • Test clicking on the section header itself
  3. Test Quick Add:
    • Click the + button on a gear item
    • Verify item is added to the pack
    • Check that quantity can be changed
  4. Test Saving:
    • Create a new pack or edit existing
    • Add several items via drag & drop
    • Click "Save Pack"
    • Navigate away and come back
    • Load the pack and verify items are preserved
