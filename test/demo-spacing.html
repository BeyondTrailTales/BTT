Text Measure Utilities

Optimal line lengths for readability:

Normal Width

This text is constrained to an optimal reading width using .text-measure (65ch). This ensures comfortable reading by preventing lines from becoming too long, which can cause readers to lose their place when moving to the next line.

Narrow Width

Using .text-measure-narrow (45ch) for even more constrained text blocks, useful for sidebars or secondary content areas.

Wide Width

The .text-measure-wide class (80ch) allows for slightly longer lines while still maintaining readability. This is useful for technical documentation or code examples where more horizontal space might be beneficial.
