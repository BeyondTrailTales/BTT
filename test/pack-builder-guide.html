🎒 Pack Builder User Guide

Welcome to the BeyondTrailTales Pack Builder!
This tool helps you organize and manage your backpacking gear efficiently.

📋 Quick Start

Open Pack Builder: Navigate to /BTT/public/backpacks.php
Create Your First Pack: Click the "New Pack" button in the top-right corner
Add Details: Enter pack name, description, and capacity
Add Gear: Drag items from the gear library to your pack sections
Save: Click "Save Pack" to store your configuration

🔧 Core Features

1. Pack Management

  • Create: Build unlimited pack configurations
  • Edit: Modify existing packs anytime
  • Delete: Remove unwanted packs
  • Duplicate: Copy packs as templates

2. Section Organization

  • Main Compartment: Primary storage area
  • Top Lid: Quick access items
  • Side Pockets: Water bottles, snacks
  • Custom Sections: Add your own sections

3. Gear Library

  • Default Gear: Pre-configured common items
  • Custom Gear: Add your specific equipment
  • Categories: Organized by type (shelter, cooking, etc.)
  • Weight Tracking: Automatic weight calculations

💻 How to Use

Creating a Pack

Click "New Pack" button or press the ➕ icon
Enter pack details in the right panel
Browse gear library and drag items to sections
Adjust quantities using the number inputs
Click "Save Pack" when complete
Use the search bar to quickly find specific gear items

Managing Sections

Click "Add Section" to create custom compartments
Name your section (e.g., "Electronics Pouch")
Drag items between sections to reorganize

Weight Management

Weight Categories:
  • Total Weight: Everything in your pack
  • Base Weight: Non-consumable gear
  • Worn Weight: Items you wear (not in pack)
  • Consumables: Food, water, fuel
Remember to update quantities for consumables based on trip duration

🐛 Troubleshooting

Common Issues:
  • Packs not loading: Refresh the page (F5)
  • Can't drag items: Ensure JavaScript is enabled
  • Save fails: Check internet connection
  • Missing gear: Try "All Gear" view mode
